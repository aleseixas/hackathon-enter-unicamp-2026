# Hackathon Enter @ UNICAMP 2026

Repositório da equipe para o Hackathon Enter na UNICAMP.

## Estrutura

```text
├── src/                  # código-fonte da solução
├── data/                 # dados de exemplo (não incluir dados sensíveis)
├── docs/                 # apresentação final e documentação
│   └── presentation.*    # slides ou documento para a apresentação
├── .env.example          # exemplo de variáveis de ambiente
├── SETUP.md              # instruções de instalação e execução
└── README.md             # visão geral do projeto
```

## Objetivo

Desenvolver a solução do desafio proposto pela Enter durante o hackathon. Este README deve ser atualizado ao longo do evento com:

- problema e hipótese da equipe;
- política/regra de decisão proposta;
- arquitetura da solução;
- experiência do usuário;
- resultados e métricas;
- limitações e próximos passos.

## Desenvolvimento

Consulte [`SETUP.md`](./SETUP.md) para instruções de ambiente, instalação e execução.

## Dados

Arquivos sensíveis ou bases fornecidas durante o hackathon não devem ser versionados. Consulte [`data/README.md`](./data/README.md).

## Entrega

A documentação e a apresentação final devem ficar em [`docs/`](./docs/).
